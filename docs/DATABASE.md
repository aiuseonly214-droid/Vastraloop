# Database Schema & Data Models

Derived from PRD, Frontend data requirements, and Architecture specifications.

## 1. Entities & Fields

### User (`users`)
- `id` (String, Primary Key)
- `name` (String, Required)
- `phone` (String, Unique, Required, Indexed)
- `email` (String, Unique, Required, Indexed)
- `passwordHash` (String, Required - never exposed)
- `city` (String, Default: "Nashik, Maharashtra")
- `address` (String)
- `verifiedId` (Boolean, Default: false)
- `role` (Enum: `'customer' | 'owner' | 'admin'`, Default: `'customer'`)
- `createdAt` (ISO Date String)
- `updatedAt` (ISO Date String)

### OutfitItem (`outfits`)
- `id` (String, Primary Key)
- `title` (String, Required, Indexed)
- `boutique` (String, Required, Indexed)
- `boutiqueAddress` (String, Required)
- `boutiquePhone` (String, Required)
- `location` (String, Indexed) - Nashik neighborhoods (College Road, Gangapur Road, Main Road, Canada Corner, Mahatma Nagar)
- `pricePerDay` (Number, Required, Indexed)
- `deposit` (Number, Required)
- `rating` (Number, Default: 5.0)
- `reviewsCount` (Number, Default: 0)
- `size` (String, Required, Indexed)
- `availableSizes` (Array of Strings)
- `fabric` (String)
- `fit` (String)
- `cancellationPolicy` (String)
- `deliveryOptions` (String)
- `images` (Array of Strings, Required)
- `category` (Enum: `'Sherwani' | 'Lehenga' | 'Tuxedo' | 'Saree' | 'Indo-Western' | 'Kurta' | 'Gown'`, Indexed)
- `gender` (Enum: `'Men' | 'Women' | 'Kids' | 'Unisex'`, Indexed)
- `occasion` (Enum: `'Wedding' | 'Festivals' | 'Party Wear' | 'Reception' | 'Sangeet' | 'Traditional'`, Indexed)
- `isBoutiqueVerified` (Boolean, Default: true, Indexed)
- `description` (String)
- `bookedDates` (Array of Numbers - reserved day numbers)
- `available` (Boolean, Default: true, Indexed)
- `createdAt` (ISO Date String)

### RentalOrder (`orders`)
- `id` (String, Primary Key)
- `orderNumber` (String, Unique, e.g., `#VL-8821`, Indexed)
- `customerId` (String, Foreign Key -> User, Indexed)
- `customerName` (String, Required)
- `customerPhone` (String, Required)
- `outfitId` (String, Foreign Key -> Outfit, Indexed)
- `outfitTitle` (String, Required)
- `outfitImage` (String)
- `boutique` (String, Required, Indexed)
- `boutiqueAddress` (String)
- `boutiquePhone` (String)
- `durationDays` (Number, Required)
- `startDate` (String, Required)
- `endDate` (String, Required)
- `fulfillmentType` (Enum: `'delivery' | 'pickup'`, Required)
- `deliveryAddress` (String, Optional)
- `pickupLocation` (String, Optional)
- `paymentMethod` (Enum: `'upi' | 'card' | 'cash'`, Required)
- `rentalFee` (Number, Required)
- `depositFee` (Number, Required)
- `deliveryFee` (Number, Required)
- `totalAmount` (Number, Required)
- `status` (Enum: `'confirmed' | 'ready_for_pickup' | 'in_use' | 'return_pending' | 'inspection' | 'deposit_refunded' | 'completed' | 'cancelled'`, Indexed)
- `timeline` (Array of TimelineEvent objects)
- `inspectionNotes` (String, Optional)
- `depositRefundAmount` (Number, Optional)
- `damageReported` (Boolean, Default: false)
- `createdAt` (ISO Date String, Indexed)
- `updatedAt` (ISO Date String)

### DamageClaim (`claims`)
- `id` (String, Primary Key)
- `orderNumber` (String, Required, Indexed)
- `orderId` (String, Foreign Key -> Order, Indexed)
- `itemTitle` (String, Required)
- `reportedBy` (String, Required)
- `issueType` (Enum: `'Stain' | 'Tear / Rip' | 'Missing Accessory' | 'Late Return'`, Required)
- `claimedAmount` (Number, Required)
- `status` (Enum: `'Pending Admin Review' | 'Approved' | 'Rejected' | 'Adjusted'`, Default: `'Pending Admin Review'`, Indexed)
- `evidenceDescription` (String, Required)
- `evidenceImage` (String, Optional)
- `resolutionNotes` (String, Optional)
- `createdAt` (ISO Date String)
- `resolvedAt` (ISO Date String, Optional)

### BoutiquePartner (`boutiques`)
- `id` (String, Primary Key)
- `name` (String, Required)
- `location` (String, Required)
- `address` (String, Required)
- `phone` (String, Required)
- `verificationType` (String - GSTIN / Shop Act ID / Trade License)
- `isVerified` (Boolean, Default: true)
- `totalEarnings` (Number, Default: 0)
- `bankAccountSummary` (String)

## 2. Indexing Strategy
- Multi-field composite index for Outfits on `[gender, occasion, category, pricePerDay]`.
- Index on `orders.customerId` and `orders.status` for fast active/completed customer lookups.
- Unique index on `users.email` and `users.phone`.
- Unique index on `orders.orderNumber`.

## 3. Soft Deletion & Audit Requirements
- Listings set `available: false` instead of hard deletion when referenced in active rental orders.
- Order timeline audit log maintains full trace of status changes with timestamps.
